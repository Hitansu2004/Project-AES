VIEWPORT TIERS (single source of truth in RoseShell.module.css)
─────────────────────────────────────────────────────────────────
  • Mobile   ≤768 px  → glass top app bar + bottom nav + drawer sidebar
  • Tablet   769–1023 px → persistent slim 200 px sidebar + tight topBar
  • Desktop  ≥1024 px → persistent 240–260 px sidebar + full topBar
  • Wide     ≥1440 px → 64 px luxury margins

Independence guarantees:
  • Mobile rules:  @media (max-width: 768px)
  • Tablet rules:  @media (min-width: 769px) and (max-width: 1023px)
  • Desktop rules: @media (min-width: 1024px)
  No 1-pixel overlap. No collision. Page modules use the same breakpoints.

Focused-flow chrome (wizards + detail pages):
  RoseShell prop `focused` → hides sidebar, topBar, mobileNav, bottomNav
  and footer on ALL viewports. Pages render their own minimal back header.
